\# Kenya Real Estate Market Analysis \& Property Price Prediction



\## Project Objective



This project analyses residential property-for-sale data in Kenya to understand

the factors associated with property prices and develop machine-learning models

for property price prediction.



\## Main Research Question



What factors influence residential property prices in Kenya, and how accurately

can machine-learning models predict the asking price of a property?



\## Initial Scope



\- Residential properties

\- Properties for sale

\- Kenya

\- Property-level analysis

\- Exploratory data analysis
